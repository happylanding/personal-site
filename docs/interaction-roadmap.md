## 一、9 个可改进点（按优先级）

### 🔴 P0 先修（已随 PR #10 一并合入）

1. **宠物层级 z-index 修正**
   - 背景：`.pet` 原为 `z-index: 60`，低于 Header（`z-70`）与阅读进度条（`z-80`）。
   - 修复：改为 `z-index: 90`（导航之上、搜索弹窗 `z-100` 之下）。
   - 兜底：新增 `pet-hidden` 类，搜索弹窗（`search-overlay-open`）与移动端菜单（`mobile-overlay-open`）打开时隐藏宠物，彻底避免层级/遮挡问题。
   - 状态：✅ 已在 PR #10 分支完成

2. **宠物放置位避开「回到顶部」按钮**
   - 背景：宠物默认在左下角，BackToTop 在右下角 `right-8`，本身不冲突；但拖拽后可能重叠。
   - 修复：拖拽过程中实时检测与 `#back-to-top` 的矩形碰撞，重叠时自动把宠物弹到按钮左侧。
   - 状态：✅ 已在 PR #10 分支完成

3. **ScrollReveal 阈值回退**
   - 背景：`threshold: 0.1` 会令超长文章（10% 高度超过视口）永不触发，内容一直 `opacity: 0`——这是 main 上 `a65bad1` 已修复的坑。
   - 修复：回退为 `threshold: 0`（任意可见即触发），并新增 **3s 强制 reveal 兜底**，防止极端情况内容不可见。
   - 状态：✅ 已在 PR #10 分支完成

### 🟡 P1 推荐（已随 PR #10 完成一部分）

4. **宠物→内容联动**
   - 滚动跟随：桌面端宠物随滚动在阅读区块间上下浮动（复用 `IntersectionObserver` 思路，采用 rAF 合并）。
   - 节令问候：按「周末 / 早晨 / 下午 / 傍晚 / 深夜」切换问候语，30% 概率在点击时说出。
   - 状态：✅ 已在 PR #10 分支完成（后续可与方案 B 的 ScrollTrigger 复用同一监听）

5. **宠物视觉升级：形象微调 + 主题跟随**
   - 加 2-3 个 SVG 姿态（挥手 / 抱书 / 睡觉），配合节令切换；
   - 暗色模式加 `dark` 变体（墨绿 + 暗金瞳孔）；
   - `prefers-reduced-motion` 下「完全静止」兜底（眨眼 / 瞳孔 / 浮动 / 姿态全部静止）。
   - 状态：✅ 已完成（挥手 / 抱书 / 睡觉三姿态按时段自动切换；dark 变体墨绿 + 暗金瞳孔；reduced-motion 完全静止）

6. **文案与双语补全**（待立项）
   - 台词里插站内真实内容（Currently 的书名、最新文章标题）；
   - 字数控制在 20 字内（气泡宽 190px，超长换行难看）。

### 🟢 P2 锦上添花（后续立项）

7. **宠物「角色成长」彩蛋** — 配合方案 C 的 About 叙事，滚动进度 → 宠物成长条（小萌新 → 老学究）。
8. **宠物与 Currently 联动** — PR #11 动态卡片生成后，宠物点击气泡引用真实内容（在读哪本书 / 最近写了什么）。
9. **性能与体验兜底**
   - `mousemove` 瞳孔、`IntersectionObserver`、滚动跟随统一 rAF 合并（瞳孔已做，其余照做）；
   - 移动端 84px 宠物支持最小化/隐藏开关（长按收进角落）。

## 四、约束与注意事项

1. **技术栈**：纯 Astro SSG + 无框架组件，优先原生 JS / 纯 CSS，避免引入 React 运行时。
2. **无障碍**：所有动效支持 `prefers-reduced-motion: reduce` 降级。
3. **性能**：统一 rAF 合并，避免滚动/移动事件高频触发。
4. **双语**：所有交互文案同步中英 i18n 字典（`src/i18n/ui.ts`）。
5. **层级规范**：Header `z-70` / 进度条 `z-80` / 宠物 `z-90` / 搜索弹窗 `z-100`。
