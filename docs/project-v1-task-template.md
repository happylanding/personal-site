# 个人网站改造V1：任务模板

> 复制本模板创建 `V-###`、`A-###`、`F-###`、`T-###` 或 `Q-###` 任务。一个任务只解决一个读者问题；跨轨任务必须写清主轨和协作轨。

## 任务信息

| 字段 | 内容 |
| --- | --- |
| 任务代号与名称 | `轨道-编号：动词 + 对象` |
| 主轨 / 协作轨 | 视觉 / 架构 / 功能 / 文本与内容 / 质量与交付 |
| 用户问题 | 读者或维护者遇到的具体问题 |
| 目标页面或对象 | 路由、组件、内容集合或流程 |
| 非目标 | 本任务明确不处理的范围 |
| 依赖决策 | 相关 `DESIGN.md` 规则、蓝图、内容边界或前序任务 |

## 实施简报

请用完整句子说明本任务如何服务于“中文研究工作台”定位，何处需要遵循纯色 `#10131d` 画布、内容优先、中文可读性、公开边界和低干扰动效。若需求会影响栏目结构、身份公开边界、许可规则或生产分支，先取得用户确认。

## 验收标准

| 类型 | 验收项 | 核验方式 |
| --- | --- | --- |
| 行为 | 写出读者能完成的动作或维护者能完成的更新 | 浏览器回归 / 手动键盘路径 |
| 视觉 | 写出 1440px、834px、390px 下的层级、触控或无溢出要求 | 三视口截图 |
| 内容 | 写出真实性、脱敏、授权与中文风格要求 | 内容复核 / schema 校验 |
| 质量 | 写出必须运行的命令和无障碍范围 | `npm run quality`、Playwright、axe |

## 实施记录

| 阶段 | 结论 |
| --- | --- |
| 红灯或基线 | 失败测试、现有截图或已知问题 |
| 代码与内容变更 | 文件列表与关键设计/架构取舍 |
| 质量结果 | 类型、构建、回归、axe、截图结果 |
| Git 交付 | 分支、提交、预览链接 |

## 交付结论

| 段落 | 最终填写内容 |
| --- | --- |
| 验收标准 | 预先承诺的可观察结果 |
| 实际结果 | 已实现内容及刻意不做的部分 |
| 核验方式 | 命令、截图、测试和审计证据 |
| 未完成项 | 明确转入下一任务的事项 |
