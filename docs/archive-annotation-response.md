# 叩问归档页：用户标注修订简报

## 标注解读

“叩问”不再作为压过内容目录的巨型视觉符号，而是收敛为中等尺度的栏目标题，并移除句号。问题目录状态、文章数量、文章日期和标签均不再使用小于 12px 的阅读信息文字；它们应保持冷白与青绿的语义层级，但首先保证可读性。

## 筛选区改造

现有的全部标签单行轨道虽然没有裁切，但因短标签过于密集而难以扫读。改为“主题筛选”工具带：默认保留“全部”及少数具有代表性的主题，其他真实标签通过一个有状态、可键盘操作的“展开全部标签”按钮披露。展开后，补充标签使用自然换行的文本式控件，而非高饱和胶囊；收起时不隐藏当前激活的标签。

这种方案遵循可操作披露而不是裁切标签的原则，同时把筛选从装饰性信息堆叠恢复为明确的读者动作。

## 视觉边界

保持深蓝黑阅读环境、单一电紫激活信号和荧青状态信号。筛选区的视觉结构由标题、当前筛选状态、少量入口和展开动作组成；不新增统计卡、大面积框线或高饱和标签药丸。
