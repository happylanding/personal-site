# Galvin 移动端章节导航 V2 调研记录

日期：2026-08-15  
问题：当前“底部阅读定位条 → 模态章节抽屉”在选择章节时功能完整，但遮罩、面板高度和切换过程会中断长文阅读；用户反馈其页面布局也显得笨重。

## 结论

移动端文章页是典型的内容页面，首要任务是持续阅读而非高频导航。因此，目录应当在文章起点提供完整概览，并在阅读途中保留一个极轻量、非固定的“章节上下文”入口；完整目录只在用户明确需要时在原位置展开，不使用遮罩或视口底部抽屉。

建议采用 **“首屏内联目录 + 正文中的 `details` 章节索引 + 无固定底栏”**：

1. 在文章导语与正文之间保留目录入口，显示总章节数与首个当前章节；默认收起，点击后原位展开完整的锚点列表。
2. 目录使用原生 `<details>/<summary>`，展开时把正文向下推开而非覆盖。点击任一章节锚点后关闭目录并滚动到对应段落。
3. 滚动阅读中不再显示固定底部控制条或遮罩。当前章节仅更新内联目录的摘要文字与已展开目录里的 `aria-current` 项；用户向上回看目录即可获得定位和跳转。
4. 文章顶部仍保留静态“阅读路线”信息（例如“06 节 / 12 min”），使读者在刚进入文章时获得页面地图；对于短文（少于两个标题）不渲染目录。

## 证据与取舍

| 发现 | 对 Galvin 的意义 | 结构决策 |
| --- | --- | --- |
| NN/g 指出移动端目录可使用页内链接或手风琴；目录可帮助用户概览和直达相关内容。 | 保留目录价值，但它不是每秒都需要的控制器。 | 将完整章节列表放在文章开头，使用锚点直接跳转。 |
| NN/g 指出手风琴在原位置展开，会推开内容而不是叠加在内容之上。 | 与当前模态抽屉相比，原位展开不会遮住正在阅读的段落，也更符合“继续读”的心智模型。 | 以 `<details>` 内联目录替代模态抽屉。 |
| Smart Interface Design Patterns 将内容页视为“目的地”：阅读占主导，导航可被合理隐藏；长文目录可以放在页首手风琴中。 | 固定的底部目录条会持续侵占移动端阅读空间，不符合 Galvin 文章页的主任务。 | 移除滚动后的固定底部定位条。 |
| Paul Kinlan 的试验显示，只有用户主动索引时才应调出目录，避免让目录延缓“开始阅读”。 | 完整目录不应默认占据首屏主要面积。 | 目录默认折叠，摘要仅保留章节数与当前章节名。 |
| NN/g 关于渐进披露的原则是：初始仅展示核心信息，次要功能按需提供，并让进入路径清晰。 | “章节导航”属于低频辅助任务；阅读上下文属于高频信息。 | 摘要固定提供清晰入口，章节列表仅在点按后出现。 |

## 明确不采用的模式

| 模式 | 不采用原因 |
| --- | --- |
| 底部模态抽屉 | 需要遮罩、占据较大视口，打断正在阅读的内容上下文。 |
| 常驻底部导航条 | 长文阅读中持续占据垂直空间；参考模式也指出内容页应将此类固定导航做得极小或避免。 |
| 可拖拽悬浮球 | 容易遮住内容、视觉噪声较大，且增加发现与拖动成本。 |
| 将完整目录默认铺在文章标题下 | 会推迟正文第一屏的出现，增加“开始阅读”的时间。 |

## 可访问性与交互约束

目录摘要为原生可聚焦控件，使用清晰的“章节索引（N 节）”标签。每个目录项为真实锚点；当前项使用 `aria-current="location"`。摘要在点选章节后自动收起，但不夺取焦点；减少动态效果偏好下取消展开/滚动动画。无论目录是否展开，正文阅读进度条继续保留其既有 `progressbar` 语义。

## 390px 视觉核验补充

首次实现的收起摘要虽已消除遮罩与固定底栏，但标题、当前章节、章节数和箭头在单行内并列，信息密度偏高；展开后，长目录会把索引区域拉得过长。V2 的视觉收敛要求是：摘要改为两层信息（上层“章节索引 / 节数”，下层当前章节），以保证长中文标题可读；展开列表在正文流内保留，但以一个可滚动的有限高度区域承载，避免一次打开就把整篇正文推到很远的位置。该滚动区只在用户明确点按“章节索引”后出现，且不使用遮罩、不锁定页面、不固定在视口底部。

优化后的 390px 截图已确认：收起状态仅为 72px 的两行路线提示；展开状态为 528px 的原位索引区域，正文可通过目录关闭或完成跳转后立即回到视野。当前结果不含底部固定条、页面遮罩或读取期间的滚动锁定。
