# 书籍上传 · 判断流程与自动化处理指南

> 适用场景：把一本新书传到网站并生成在线阅读。
> 最终目的：**一句话就能让 CodeBuddy 完成"上传新书 + 自动生成在线阅读 + 上线"的全部后续步骤**。
> 维护：本文件沉淀了从"拿到书"到"上线可读"的完整判断流程与自动化能力，CodeBuddy 与站主共用。

---

## 一、总览：上传一本书的完整链路

```
拿到一本书
   │
   ▼ ① 版权判断（人工 / 或让 AI 初判）——最关键的红线
是否公版书（Public Domain）？
 ├─ 否（受版权保护）→ 走「书评 + 购买/借阅链接」模式，不提供文件下载/在线阅读
 └─ 是（公版书）   → 继续 ↓
   │
   ▼ ② 格式判断
PDF  /  EPUB  /  其他
 ├─ PDF  → 自动渲染成"站内原图翻页阅读"（不解析文本）
 ├─ EPUB → 自动解析出章节，生成"章节文本在线阅读"
 └─ 其他格式 → 需转成 PDF/EPUB，或另行处理
   │
   ▼ ③ 语言 / 内容判断
中文原书？外文原书？
 ├─ 中文原书 → 保持中文原文，绝不擅自翻译成英文
 └─ 外文原书 → 保持原书语言（英文书即英文原文）
   │
   ▼ ④ 是否需要精修（可选，非必须）
自动生成的是"完整原文、按文件结构切分"的原始版本
 ├─ 够用即可 → 直接上线
 └─ 想要精修 → 让 AI 基于 src/data/books/{slug}.json 二次整理
   │
   ▼ ⑤ 配图 / 简介 / 封面（可选）
自动补建的文章只有占位简介，可补充封面、简介、标签
   │
   ▼ ⑥ 预览验证（必须，涉及视觉改动）
凡是涉及阅读页/排版/视觉改动，必须先拉 .cnb.run 预览给站主确认
   │
   ▼ ⑦ 上线
CI 构建（.cnb.yml）→ 自动同步 GitHub → Cloudflare 自动部署
```

## 二、上传方式（把书放到哪里）

把公版书文件直接放进 `public/books/` 目录即可：

```
public/books/
├── xxx.pdf        ← PDF 原书
├── xxx.epub       ← EPUB 原书
└── xxx.md?        ← 不支持，请用上述两种格式
```

上传后**无需人工干预**，构建时自动解析并生成在线阅读内容。

## 三、自动化能力（已实现，无需人工）

### 3.1 自动触发时机

- **CI 构建**：`.cnb.yml` 的 `build` 阶段在 `npm run build` 前先跑 `node scripts/build-books.mjs`
- **本地**：`npm run build` / `npm run dev`（经 `astro.config.mjs` 的 `astro:build:start` 钩子自动调用）

### 3.2 自动产出的文件

```
public/books/xxx.epub 或 xxx.pdf
        │
        ▼  （scripts/build-books.mjs 自动解析）
src/data/books/xxx.json        ← 阅读页读取的章节数据
src/content/articles/xxx.md    ← 自动补建的书籍文章页（若尚无文章）
        │
        ▼
/books/xxx/read/ 在线阅读页（构建生成）
```

### 3.3 幂等 / 保护规则（关键！）

| 情况 | 行为 |
|------|------|
| 已生成 JSON 比源文件新 | 跳过，不重复解析 |
| 已存在同名文章 | 不覆盖，保留已有简介/书评 |
| JSON 已带 `textZh`/`titleZh`（已精修） | **绝不自动重新解析覆盖**，避免中文原书被重新解析成英文译本 |
| PDF 页面图片缺失/页数不符 | 自动重新渲染原图 |
| 大书章节较多 | 自动拆分懒加载 JSON，首屏变快 |

### 3.4 自动解析能力

- **EPUB**：读 `toc.ncx` + `spine` 自动切分章节，逐章提取正文（最准确）
- **PDF**：提取全文，按「第X章 / Chapter X / Book X / FIRST BOOK」等标题启发式切分；无法识别时降级为单章整本
  - ⚠️ 当前 PDF 已改为**原图展示 + 翻页**（`type:"pdf"` 的 JSON），不再解析为文本，见下方"格式判断"

## 四、判断流程详解（需要人 / AI 判断的关键点）

### 4.1 版权红线（第一条，最重要）

> ⚠️ **只有公版书（Public Domain）可提供文件下载/在线阅读；受版权保护书籍一律走「书评 + 购买/借阅链接」模式。**

| 判断 | 处理 |
|------|------|
| 公版书（如作者去世超版权年限 / 明确进入公有领域） | 可上传 `public/books/`，提供在线阅读 + 下载 |
| 受版权保护（未进入公有领域） | **不上传文件**，改为：书评文章 + `buyUrl` 购买链接 / 借阅链接 |

> 常见公版书来源：Project Gutenberg 等。拿不准版权时优先走「书评 + 购买链接」，安全第一。

### 4.2 格式判断

| 格式 | 在线阅读方式 | 说明 |
|------|------------|------|
| **EPUB** | 章节文本阅读 | 解析出章节，左侧/目录 + 正文排版阅读（体验最佳） |
| **PDF** | 原图翻页阅读 | 把每页渲染成图片，站内原图展示 + 翻页，不触发下载 |
| 其他（DOCX/MOBI/TXT…） | 需转换 | 先转成 EPUB 或 PDF 再上传 |

> 补充历史结论（Issue #115 澄清）：
> - **PDF** 采用"嵌套阅读器、站内原图打开"方式，**不**解析为裸文本；
> - **EPUB** 采用"章节文本 + 排版阅读"，**不**做目录预览面板。

### 4.3 语言 / 内容判断（不要擅自翻译）

> ⚠️ **中英文原书一律保持原始语言展示，不擅自翻译。**（Issue #115 / #128 明确要求）

| 书的情况 | 处理 |
|---------|------|
| 中文原书（如《孙子兵法》） | 中文界面展示**中文原文**，英文界面才展示英文译本；不擅自翻译正文 |
| 外文原书（如《傲慢与偏见》《沉思录》） | 保持原书语言（英文即英文原文），不擅自翻译成中文 |

> 若书的正文需要中英双语，需人工/精修时补 `textZh`/`titleZh` 字段，构建脚本会尊重精修结果、不覆盖。

### 4.4 是否需要精修（可选增强）

自动生成的章节是"完整原文、按文件结构切分"的原始版本。若想让书达到《孙子兵法》那种精修效果（精选/拆分章节/排版优化），可让 AI 基于 `src/data/books/{slug}.json` 二次整理。**精修属大改动，需先出原型图或确认再执行。**

### 4.5 简介 / 标签

自动补建的文章只带占位简介（"该书已上传，等待补充简介"）。上线后可按需补写简介、标签、`description`、校正作者、评分、`readUrl`/`epubUrl`/`pdfUrl`。**不再生成封面/配图**（见 Issue #153）。

## 五、CodeBuddy 自动化处理（一句话让 AI 干活）

### 5.1 提示词模板

> **「我上传了《书名》，帮我处理上线」**

CodeBuddy 收到后会执行：

1. **版权判断**：确认是否为公版书，非公版则改为"书评+购买链接"模式
2. **格式识别**：检测 `public/books/` 下的新文件是 PDF 还是 EPUB
3. **语言保护**：识别书语言，中文原书保持中文、外文原书保持原文，不擅自翻译
4. **跑解析**：`node scripts/build-books.mjs`，生成 `src/data/books/{slug}.json` + 自动补建文章
5. **构建验证**：`npm run build` 通过
6. **简介/标签**：补简介 + 标签（**不再生成封面/配图**，见 Issue #153）
7. **拉预览**：涉及视觉/阅读页改动时，拉起 `.cnb.run` 预览给站主确认
8. **合并部署**：小改动直接合并部署；大改动先提 PR 由站主确认

### 5.2 提交 PR / 部署

- 新建/上传书本属于内容新增，走小改动可直接合并部署；若涉及阅读器/排版重构属大改动，先出原型图、再提 PR 让站主确认
- 合并前保证 `npm run build` 通过 + CI 为 success
- 合并后 `.cnb.yml` 自动同步 GitHub → Cloudflare 部署

## 六、常见问题 / 注意事项

- **预览必给**：凡是涉及阅读页/排版/视觉/字体的改动，交付时必须附带 `.cnb.run` 预览链接（`AGENT_OPS.md` 协作规则）
- **不要擅自翻译**：正文保持原书语言
- **版权优先**：拿不准版权一律不上传文件，走书评+购买链接
- **精修保护**：已精修（带 `textZh`/`titleZh`）的书不会被构建脚本覆盖
- **PDF 是原图**：PDF 在线阅读是原图翻页，不解析文本（若希望 PDF 出文本版需另走 EPUB）
