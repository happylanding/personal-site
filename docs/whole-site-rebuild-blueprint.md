# Galvin 整站视觉与体验重构蓝图

## 一句话方向

**Galvin 是一张正在被使用的中文研究工作台：读者先看见一句真实主张，再沿着清晰的内容轨道进入工具、问题和记录。**

它不是 AI SaaS、聊天产品、赛博控制台或“个人主页模板”。它必须呈现一种安静、可信、持续更新的学习者身份：内容先出现，系统只在需要帮助判断和行动时出现。

## Brief Inference

| 项目 | 决策 |
| --- | --- |
| 领域 | AI 初学者的公开学习、造物与工作方法记录 |
| 第一分钟读者 | 同样刚开始学习 AI 的普通人 |
| 单一情绪 | **笃定**：不是炫耀完成度，而是让人相信这里有可跟随的过程 |
| 信息优先级 | 主张/内容标题 → 一句话解释 → 下一步行动 → 日期、标签、状态 |
| 动效深度 | 低：仅用于链接、筛选、披露、阅读进度和资源菜单的状态变化；缩减动态时全部静止 |
| 明确禁止 | 卡片墙、英文眉标堆叠、装饰编号、假统计、重复标题、网格/纹理/曲线/渐变等背景特效、亮白输入框、过度圆角与不必要的阴影 |

## 整站视觉语法

### 1. 一张纯色画布，三个内容层

全站使用 `#10131d` 作为唯一、纯色、非纯黑的深色画布。页面、章节和正文区不再使用网格、纹理、曲线、图片、粒子或渐变背景。首页的“此刻”不再靠背景信号场表达，而使用标题邻近的一条静态状态注释和一个低饱和色点；全站层次只由细分隔线、必要的纯色表面阶差与宽阔留白建立。

| 层 | 用途 | 视觉规则 |
| --- | --- | --- |
| 画布 | 全站阅读背景 | `--galvin-canvas: #10131d`；所有页面与章节保持同一纯色，无背景图或渐变 |
| 阅读层 | 标题、正文、连续条目 | 冷白与灰蓝文字、长行分隔、克制阅读宽度 |
| 操作层 | 搜索、筛选、资源菜单、下载、复制 | 仅在必要时使用 `--galvin-surface`；电紫表示选中/下一步，荧青只表示状态 |

### 2. 六级文字，而非每页自定字号

| 文字角色 | 1440px | 834px | 390px | 适用范围 |
| --- | ---: | ---: | ---: | --- |
| 首页主张 | 68px | 56px | 42px | 仅首页一次 |
| 页面章节 | 38px | 34px | 28px | 造物、叩问、行迹、藏页、书架、关于 |
| 条目标题 | 26px | 24px | 21px | 工具、文章、书目、资源 |
| 文章标题 | 46px | 40px | 32px | 阅读页，仅一次 |
| 引言/正文 | 18px | 17px | 17px | 说明、摘要、正文 |
| 元数据/控件 | 14px / 15px | 14px / 15px | 14px / 15px | 日期、标签、计数；必要控件不得更小 |

中文标题必须按短语进行宽度控制，使用 `text-wrap: balance` 或等效约束；移动端不允许用字级强制换行换取视觉冲击。

### 3. 统一空间与内容宽度

页面外缘分别为 1440px 下 72px、834px 下 32px、390px 下 18px。入口页可使用 1160–1280px 的不对称网格；目录页和阅读页分别收束为 1040px 与 760px 的内容轨道。章节之间保留 80px / 56px / 44px 的留白，标题、说明和第一个真实内容条目保持在一个连续视线内。

## 四种页面原型

### A. 首页：主张与路径

首页是唯一允许展示级主张的页面。首屏只能回答“Galvin 在做什么”与“我可以从哪里开始”。此刻不再是大卡片或图形背景，而是主张旁一条在进行中的静态工作注释。

```text
┌──────────────────── 首页主张 ────────────────────┐
│ Galvin / 中文 AI 学习与创作空间                    │
│ 把好奇心，做成一点有用的东西。    此刻：正在搭建… │
│ 说明文字                                            │
│ [从叩问开始]  [看正在造的东西]                     │
└─────────────────────────────────────────────────┘
  造物 →   叩问 →   行迹 →   藏页（网站与资源 / 书架）
  最近叩问：首篇优先，其余连续条目
```

### B. 内容目录：造物、叩问、藏页、书架

目录页取消“巨型英雄 + 计数盒 + 提示框 + 卡片墙”。顶部是一个紧凑的页面介绍和工具带，随后立即进入真实内容。按内容不同只改变条目元数据：工具有状态与平台，文章有日期与主题，书目有阅读状态，资源有来源与笔记。

```text
栏目标题      一句说明                    [搜索 / 筛选]
当前筛选 · 15 条结果
──────────────────────────────────────
● 条目标题                              →
  日期 · 类别 · 一句判断
──────────────────────────────────────
● 条目标题                              →
```

**造物**的首个工具必须在手机首屏出现；隐私边界折叠为紧邻工具带的一条说明。**书架**只在首本书条目中显示阅读状态和合法入口，不再在页头用“正在读 01”统计盒。**网站与资源**使用暗色内联搜索与文本筛选，绝不使用亮白输入框或蓝色胶囊。

### C. 阅读页：一次识别，连续进入正文

阅读页不再有“封面标题 + 再次大标题”。可保留一张压缩的文章识别带，或只保留标题、摘要、日期和标签。读者在一屏内看见标题并开始正文；阅读进度和桌面目录作为辅助，不得与正文竞争。

```text
← 返回叩问
AI 学习 · 2026.08.10
用 AI 重构个人网站：一场非程序员的改造实验
一句摘要与标签
──────────────────────────────────────
正文开始
```

### D. 个人档案：行迹与关于

**行迹**是时间/地点索引，使用时间、主题和短记录的连续条目，不使用装饰序号。**关于**是个人工作档案：一段身份说明、三个真实工作主题、公开边界和联系动作。它不重复首页主张，也不使用 `BASE / FOCUS / STATUS` 式系统标签。

## 共享组件规则

| 组件 | 使用页面 | 必须做到 | 禁止行为 |
| --- | --- | --- | --- |
| `PageIntro` | 所有非首页页面 | 章节标题、单句说明、必要操作在同一阅读组内 | 巨型标题、装饰编号、重复英文眉标 |
| `ContentRail` | 工具、文章、资源、书目、行迹 | 连续行、真实元数据、清晰下一步 | 大面积浮动卡片、每条独立渐变背景 |
| `FilterBar` | 造物、叩问、资源 | 当前筛选、结果数、可披露补充项 | 横向裁切、亮色胶囊、把所有标签塞进首屏 |
| `MetaLine` | 条目与阅读页 | 14px 可读元数据，节制使用 Mono | 小于 14px 的必要信息 |
| `ActionLink` | 所有页面 | 文本先行、箭头为辅助、44px 移动触控高度 | 不明含义图标、营销式按钮堆叠 |
| `QuietNote` | 首页、工具、书架、关于 | 内联、低权重、说明真实边界或状态 | 独立统计盒、厚边框告警卡 |

## 批量实施顺序

1. **基础层：** 先重写语义令牌、文字尺度、内容宽度、Header/页脚、搜索与移动菜单；将全局画布统一为纯色 `#10131d`，移除所有背景网格、纹理、曲线、渐变和早期模板残留。
2. **三页验证：** 首页验证入口构图；造物验证目录页；文章详情验证阅读页。三页通过后才扩展。
3. **系统派生：** 叩问、网站与资源、书架、行迹、关于从四种原型派生，不再逐页重新设计。
4. **质量闭环：** 每个原型在 1440px、834px、390px、缩减动态及关键交互状态下通过截图、键盘、axe、构建和浏览器回归。

## 整体确认点

后续不再逐个元素询问。只需确认以下三个系统级决策：

1. **方向：** 保持“静默仪器室”，但将科技感收敛为文字、状态色、细分隔线和交互反馈；全站采用统一的纯色深色中文编辑工作台。
2. **结构：** 采用“首页、内容目录、阅读页、个人档案”四种原型，停止为每个栏目复制巨型英雄和统计盒。
3. **顺序：** 先统一基础层，再批量完成首页、造物、文章详情，随后派生其余栏目。
