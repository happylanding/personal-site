# Galvin 关于页与公共页脚迁移调研

日期：2026-08-15  
范围：将旧版暖色“数字小窝”关于页与极简版权页脚迁入 Galvin 深色 AI 编辑系统，不改变已确认的公开身份边界。

## 现状与问题

当前关于页仍使用渐变手写标题、暖色强调、白色玻璃卡、文章轮播、四专栏卡片与“加微信”静态入口。该视觉和内容结构与 Galvin 已落地的深蓝黑画布、冷白标题、电紫/荧青状态色和“AI 初学者 × 数字政府/数字经济从业者”的定位不一致；同时，文章统计在页面渲染时显示为零，轮播和倾斜交互也把关于页的关注点从身份、学习方向与联系入口分散到装饰。

公共页脚目前只有版权文字和两个几乎不可见的隐藏入口。它保留了站主快捷访问，但没有向到达长页面末尾的读者呈现可预期的站点跳转、公开联系渠道或内容边界。

## 结构选择

关于页将重构为一个单列、非对称节奏的“工作档案”页面：

1. **身份信号**：以 `ABOUT / 07`、Galvin、南京和一句明确的自我定位建立可扫描的第一屏，而不是使用拟人化“数字小窝”叙事。
2. **正在构建**：用三个简洁的条目说明 AI 学习、工作中的效率实验和可公开的写作/工具边界；不公开单位、项目文件或真实中文名。
3. **学习与生活基线**：将力量训练、咖啡、阅读作为低权重的个人节奏，而非独立的生活方式模块或装饰性故事。
4. **联系协议**：仅展示用户确认公开的邮箱和 X；邮箱使用复制按钮并提供状态反馈，X 为明确标记的外部链接。不渲染微信/公众号等未确认公开的入口。
5. **站点索引**：以少量明确栏目链接和“从内容开始”的返回路径代替重复的四张首页式卡片。

公共页脚将成为稳定的“结束界面”，而非隐藏图标行：左侧显示主张和版权，右侧分组显示栏目、联系与站点边界；隐藏式快捷入口继续保留给站主，但其可访问名称和键盘快捷方式不能替代可见导航。

## 可用性依据与迁移约束

| 外部发现 | Galvin 约束 |
| --- | --- |
| 页脚是用户在长页面底部寻找联系信息、社交链接和替代导航的预期位置；内容必须清晰、可发现、字体可读。[1] | 页脚显示有限且有分组的主栏目、X 与邮箱；避免仅依赖小图标和隐藏文本。 |
| 长页面可以在页脚提供与顶部相呼应的一级导航，但不应把完整站点地图塞入底部。[1] | 只展示 Galvin 七栏目的一层链接；不复制标签、文章或工具明细。 |
| 深色界面需依靠相邻表面颜色、边界与足够对比表达层级；细灰分隔线、过薄字体和过饱和文本会削弱可读性。[2] | 使用既有 `--galvin-canvas`、`--galvin-surface`、`--galvin-line` 和文字层级；只将紫/青用于状态、链接与小信号。 |
| 信息架构的目标是让内容能被直观地查找和发现，标签、链接及其位置都是结构的一部分。[3] | 关于页不再重复所有首页内容；每个区块只服务身份理解、联系或明确的下一步。 |

## 验收约束

桌面、平板与 390px 移动端必须维持连续单栏阅读和可见焦点。邮箱复制必须键盘可触发并反馈“已复制”；`mailto:` 仍作为非脚本回退。外部 X 链接必须使用 `target="_blank"` 与 `rel="noopener"`。在减少动态效果偏好下，不自动播放轮播、不显示非必要入场动效。原有页脚隐藏入口及其 `g` → `s`、`t` 快捷访问应持续有效。

## 桌面视觉核验

1440px 截图确认首屏以冷白大标题、低对比工作网格和紫/青信号建立清晰主次关系；身份、地点、关注方向以三列元数据收束，没有旧版白色玻璃卡或暖色手写标题。页面尾部的联系协议、内容入口与公共页脚形成连续的三层结束界面：先联系、再选择下一篇内容、最后是稳定的站点导航和底部公开联系入口。页脚不再依赖仅供站主使用的微小图标作为读者导航。

390px 截图确认大标题在三行内完整呈现，身份字段转为标签—值的窄屏行，未出现横向溢出。页脚按身份、栏目、联系、版权四段连续排列；七个栏目维持三列可扫描网格，邮箱复制与 X 外链保留足够的点击间距和可见文本标签。
