# 正文排版规范

> 最后更新：2026-08-21
> 适用范围：站点文章正文（`.article-content` / `.prose`）与书籍在线阅读器（`.book-reader`）。

本文档统一约定正文的**行高、行宽、中文字体**三项核心排版参数，作为全站改版与后续维护的依据。

---

## 1. 设计原则

正文是信息承载的主体，排版以「**易读、舒展、沉稳**」为准则：

- **行高**：宁疏勿密。中文每行文字更密，行高需留足呼吸感，保证换行不粘连。
- **行宽**：宁窄勿宽。每行字数过多会显著降低长文阅读节奏，需控制在舒适阅读宽度内。
- **中文字体**：正文统一使用**宋体**，衬线字在长文本中比黑体/无衬线更耐读、更具「书卷气」；书籍阅读部分同样切换为宋体，与站点正文一致。

---

## 2. 字体规范

### 2.1 中文字体

正文（含文章正文、书籍阅读器中文正文）统一使用宋体字族：

```css
--font-song: "Songti SC", "STSong", "SimSun", "宋体", "Noto Serif SC", "Source Han Serif SC", serif;
```

> 说明：
> - 优先使用 macOS / iOS 系统宋体 `Songti SC` / `STSong`；
> - 回退到 Windows 系统宋体 `SimSun` / `宋体`；
> - 最后回退到思源宋体 `Noto Serif SC` / `Source Han Serif SC`，保证跨平台一致；
> - 拉丁字符由 `serif` 兜底为站点衬线体。

### 2.2 英文字体

英文正文保持衬线体，由 `--font-serif`（Playfair Display / Georgia 系）承载，不随中文改动。

### 2.3 标题 / 界面

标题与界面元素维持现有字体体系（`--font-serif` 标题、`--font-sans` 界面），不纳入正文规范。

---

## 3. 行高规范

| 场景 | 行高（line-height） |
|------|---------------------|
| 文章正文（`.article-content`） | `1.9` |
| 书籍阅读器中文正文（`.book-reader.lang-zh`） | `2` |
| 段落间距 | 段后 `1em` |

> 中文正文行高略高于英文（中文无词间留白，视觉密度更高），书籍阅读场景可再放宽一级获得更强呼吸感。

---

## 4. 行宽规范

| 场景 | 行宽（max-width） |
|------|-------------------|
| 文章正文（`.article-content`） | `42rem`（约 672px，含目录栏时正文列自适应） |
| 书籍阅读器（`.book-reader`） | `38rem`（约 608px） |

> 正文在 `.article-grid`（含右侧目录栏）内随列自适应收缩，无需额外内层限制；无目录回退单栏时由上述 `max-width` 约束，避免过宽。

---

## 5. 实现位置

- 字体变量：`src/styles/global.css` 的 `@theme` 块新增 `--font-song`。
- 文章正文：`src/styles/global.css` 的 `.article-content` 排版区。
- 书籍阅读器：`src/styles/global.css` 的 `.book-reader` 排版区。

---

## 6. 校验清单

改版后逐项核对：

- [ ] 文章正文中文为宋体、英文为衬线体
- [ ] 文章正文行高 = 1.9，行宽 ≤ 42rem
- [ ] 书籍阅读器中文正文为宋体、行高 = 2、行宽 ≤ 38rem
- [ ] 暗色模式下配色不受影响
- [ ] 移动端（无目录单栏）行宽约束生效
