# 正文排版规范

> 最后更新：2026-08-21
> 适用范围：站点文章正文（`.article-content` / `.prose`）与书籍在线阅读器（`.book-reader`）。

本文档统一约定正文的**行高、行宽、中文字体**三项核心排版参数，作为全站改版与后续维护的依据。

---

## 1. 设计原则

正文是信息承载的主体，排版以「**易读、舒展、沉稳**」为准则：

- **行高**：宁疏勿密。中文每行文字更密，行高需留足呼吸感，保证换行不粘连。
- **行宽**：宁窄勿宽。每行字数过多会显著降低长文阅读节奏，需控制在舒适阅读宽度内。
- **中文字体**：正文统一使用**宋体**，衬线字在长文本中比黑体/无衬线更耐读、更具「书卷气」；书籍阅读部分同样切换为宋体，与站点正文一致。

---

## 2. 字体规范

### 2.1 中文字体

正文（含文章正文、书籍阅读器中文正文）统一使用宋体字族，且**优先使用思源宋体**（`Noto Serif SC`，已随站点 web 字体加载），回退系统宋体：

```css
--font-song: "Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", "宋体", serif;
```

> 说明：
> - 优先使用思源宋体 `Noto Serif SC`（站内已加载的 web 字体），笔画更实、屏幕渲染更清晰，避免 macOS `Songti SC` / Windows `SimSun` 等系统宋体在常规字重下过细、可读性差的问题；
> - 回退顺序依次为思源宋体 → macOS / iOS `Songti SC` / `STSong` → Windows `SimSun` / `宋体`，保证跨平台可用；
> - 文章正文额外使用 `font-weight: 500`（已加载 500 字重），在不失衬线书卷气的前提下进一步提升可读性；
> - 拉丁字符由 `serif` 兜底为站点衬线体。

### 2.2 英文字体

英文正文保持衬线体，由 `--font-serif`（Playfair Display / Georgia 系）承载，不随中文改动。

### 2.3 标题 / 界面

标题与界面元素维持现有字体体系（`--font-serif` 标题、`--font-sans` 界面），不纳入正文规范。

---

## 3. 行高规范

| 场景 | 行高（line-height） |
|------|---------------------|
| 文章正文（`.article-content`） | `1.9` |
| 书籍阅读器中文正文（`.book-reader.lang-zh`） | `2` |
| 段落间距 | 段后 `1em` |

> 中文正文行高略高于英文（中文无词间留白，视觉密度更高），书籍阅读场景可再放宽一级获得更强呼吸感。

---

## 4. 行宽规范

| 场景 | 行宽（max-width） |
|------|-------------------|
| 文章正文（`.article-content`） | 桌面（≥1024px，有目录栏）`min(100%, 58rem)`，正文列自适应填满，仅保留与目录的网格间距；移动/单栏 `42rem` |
| 书籍阅读器（`.book-reader`） | `38rem`（约 608px） |

> 正文在 `.article-grid`（含右侧目录栏）内随列自适应收缩，桌面端不再用固定 `42rem` 限制正文列宽度（避免与目录之间出现大段空白），只以 `min(100%, 58rem)` 兜底防止超宽屏上行过长；无目录回退单栏时由 `42rem` 约束，避免过宽。

---

## 5. 实现位置

- 字体变量：`src/styles/global.css` 的 `@theme` 块新增 `--font-song`。
- 文章正文：`src/styles/global.css` 的 `.article-content` 排版区。
- 书籍阅读器：`src/styles/global.css` 的 `.book-reader` 排版区。

---

## 6. 校验清单

改版后逐项核对：

- [ ] 文章正文中文为宋体（优先思源宋体）、英文为衬线体
- [ ] 文章正文行高 = 1.9、字重 = 500，行宽桌面自适应 ≤ 58rem / 单栏 ≤ 42rem
- [ ] 桌面端正文列与目录间无大段空白，仅保留网格间距
- [ ] 书籍阅读器中文正文为宋体、行高 = 2、行宽 ≤ 38rem
- [ ] 暗色模式下配色不受影响
- [ ] 移动端（无目录单栏）行宽约束生效
