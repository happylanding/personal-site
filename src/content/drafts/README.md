# 草稿箱

## 使用方式

把写好的文章草稿丢进来，然后在 CodeBuddy 里说：

> 帮我处理草稿箱里的文章

智能体会自动：
1. 扫描本目录下的 `.md` 文件
2. 分析内容，生成 Meta 信息（title/description/tags/section）
3. 展示给你确认
4. 确认后将正式文件写入 `src/content/articles/` 并提交发布

## 草稿格式

随便写，没有格式要求。最简形式：只写正文就够。

但建议至少写一个标题（`# 标题`），这样智能体能更准确地分析。

```markdown
# 我的文章标题

正文第一段...

## 小节一
...

## 小节二
...
```

不用写 frontmatter，不用写日期，不用写标签——全部由智能体生成。
